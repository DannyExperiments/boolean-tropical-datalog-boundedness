# Claim scope and limitations

- The main separation concerns naive parallel rounds, with a fixed program and arbitrary finite databases. It gives two rounds for every Boolean intensional predicate and unbounded tropical rounds for the target.
- Tropical input annotations are nonnegative integers and infinity. Present path edges in the example have numeric weight zero; an absent edge has infinity.
- The companion circuit statement concerns one target, with nonnegative integer circuit constants or infinity and binary min-plus gates. Its Boolean internal reachability relation need not stabilize in constant time.
- The matching circuit bound counts arithmetic depth by number of input facts, independent of coefficient bit size. The general depth classification remains open.
- Partial Lean checks a concrete trace and algebraic properties. Python exact checks are finite controls. The all-input proofs are in the manuscript.
